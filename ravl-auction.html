How This App Works

1. Setup

This is a single HTML file — there is no server. Everything is saved in this browser's localStorage, so it survives page reloads on the same device. Start in the Setup tab: set your currency symbol, minimum bid increment, countdown duration, whether the timer or the admin decides when a player is sold, and add your captains with their budgets.

2. Players

Upload a CSV or add players by hand. Expected columns: 
player_name,team,position,base_price,notes
John Smith,Team A,Setter,100,Left-handed
Alice Johnson,Team B,Outside Hitter,150,
Only player_name is required — everything else defaults sensibly if left out.

3. Running the Auction

On the Live Auction tab, sign in as Admin to nominate players and control the sale, or sign in as a Captain to place bids. The admin picks a player from the "available" list and clicks Start Bidding. Captains click Place Bid to bid the next valid amount (base price, then increments). Every new bid resets the countdown so nobody gets sniped unfairly. When the timer runs out (or the admin clicks Sell, depending on your close-mode setting), the player is assigned to the highest bidder and their budget is deducted automatically.

4. Multi-Device / Multi-Tab Play

This file only syncs automatically between browser tabs on the same device (via localStorage events) — for example, open one tab for the Admin and one tab per captain on a shared laptop, or hand a tablet around. It does not sync across separate phones/computers on its own, since there's no backend server.

Want real multi-device sync? The cleanest free option is Google's Firebase Realtime Database (or Firestore): create a free Firebase project, replace the saveState()/loadState() functions in this file's <script> with calls to the Firebase SDK (set()/onValue()), and every connected device will see live updates. Alternatively, a tiny WebSocket or Supabase backend works the same way — the important part is swapping the local persistence layer for a networked one while keeping the rest of the UI logic unchanged.

5. Results & Export

The Results tab shows sold/unsold players and final captain budgets, and lets you export everything as JSON (full backup) or CSV (a simple results sheet). Reset Tournament wipes all saved data on this device — use it to start a fresh auction.

Hosting

Just open this file directly in a browser, or drag it onto Netlify / GitHub Pages / any static host. No build step, no dependencies, no server required.
